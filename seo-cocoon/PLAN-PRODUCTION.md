# Plan de production éditoriale — pluscestsimple.com
## Data-backed (GSC + Haloscan + SEMrush hello-hello) · 2026-06

> **Principe directeur (prouvé par SEMrush) : les ARTICLES font le trafic (91 %), le cocon fait le maillage.**
> On produit des articles dans des formats prouvés, sur une structure de cocon légère. On ne mise AUCUN trafic sur les pages catégories.

---

## 0. Les 5 règles du plan
1. **Articles d'abord, cocon en plomberie.** Les pages pièces/styles/couleurs servent le maillage + hébergent les boucles d'articles ; elles ne rankent pas → créées en brouillon, publiées quand garnies.
2. **Force = travaux technique + crossover technique-déco.** C'est notre terrain (GSC) et celui où hello-hello est faible (cuisine siporex, mobilier maçonné, douche ext. = pos 1 chez eux, on peut dominer).
3. **Filtre intention : éditorial-rankable only.** On exclut les SERP e-comm/cuisinistes (« cuisine {style} », « X pas cher »). On vise informationnel + navigational (avis marque).
4. **Monétisation display** → volume + pages/session + maillage dense. Affiliation = test isolé plus tard.
5. **Drip + qualité.** Publication par lots, pipeline SERP→brief→rédac→review, 1 image, FAQ, « L'essentiel », maillage intra-silo.

## 3. Roadmap en vagues (cohérente STRATEGIE-SEO)
- **VAGUE 1 — Capitaliser le technique (ROI max).** Hubs mur porteur + charpente + maçonnerie · 4 articles mur porteur · couler une chape · **crossover (cuisine siporex/béton cellulaire, mobilier maçonné, douche extérieure)** · renfort des 5 pépites. → notre force + notre edge, là où hh est faible.
- **VAGUE 2 — Déco à fort volume / faible concurrence.** Couleur-tendance (terracotta, lie de vin, vert de gris) · cluster déco chambre · pages styles quick-win (méditerranéen, japandi, campagne-chic) · extension maison.
- **VAGUE 3 — Extension + autorité.** Clusters placo/parquet/humidité · haussmannien · jardin entretien · styles Tier 1 (scandi/industriel/bohème) + salon/chambre · réno énergétique éditoriale · alternatives à IKEA.
- **VAGUE 4 — Marques & saisonnier (+ test affiliation isolé).** Avis marques niche (Tikamoon, Tolix…) · gift guides · surélévation · gazon.

## 4. Process de production (par article)
1. **SERP** (thread principal, web-search) → vérifier intention éditoriale + concurrents.
2. **Brief** (cf. BRIEF.md mur-porteur comme gabarit) : kw cible, intent, H1, structure Hn, longueur, sujets obligatoires, différenciateurs, **maillage interne** (hub + frères), meta.
3. **Rédaction** (registre A technique / B déco selon silo ; jamais de fait/prix inventé).
4. **Review** (modèle ≠ rédac, type Opus) : hallucinations, intention, maillage, anti-cannibalisation.
5. **Intégration** : « L'essentiel » en tête + FAQ + 1 image + catégorie cluster + bloc « À lire dans le même univers ».
6. **Drip** : publication par lots après ta relecture.

## 5. Le cocon (plomberie) — ce qu'il faut quand même monter
Léger, en brouillon, publié quand garni (héberge les boucles + le maillage) :
- /decoration/par-piece/{salon,chambre,chambre-enfant,cuisine,salle-a-manger,salle-de-bain,bureau,entree}
- /decoration/styles/{scandinave,japandi,boheme,industriel,mediterraneen,campagne-chic,vintage,coloree}
- /decoration/couleurs/ (hub léger)
- /travaux/gros-oeuvre/{mur-porteur,charpente,maconnerie}
- /architecture/styles-epoques/haussmannien · /architecture/extensions/

## 6. Cibles de performance
- Vague 1 = ROI le plus rapide (force + crossover).
- ≥60 % de l'effort éditorial sur travaux/technique tant qu'il porte le trafic.
- Mesure : positions GSC des clusters, pages/session (display), pos des pépites renforcées.
