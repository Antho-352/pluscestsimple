# hello-hello.fr — Design system & tokens (extraits du HTML/CSS)

## Stack technique
- **WordPress** + thème **Blocksy** + **Elementor** (page builder) + Stackable (blocs) + url-shortify (liens affiliés masqués) + wp-featherlight (lightbox images).
- Donc : site visuel construit au page builder, lourd en plugins (≠ notre thème custom léger).

## Typographies
- **Lato** (400-700) — corps de texte, sans-serif humaniste, lisible.
- **Montserrat** (100-900) — titres, sans-serif géométrique.
- **Dancing Script** (700) — script manuscrit décoratif (accents, touches "signature", féminin).
→ Pairing : 2 sans-serif (corps Lato / titres Montserrat) + 1 script d'accent.

## Palette de couleurs
- **Accent signature : `#f00069`** (magenta/rose vif) — couleur de marque forte, CTA, liens.
- Base : `#fffffe` / `#ffffff` (blanc cassé), `#f6eee7` (crème/beige chaud).
- Texte : `#0f0e17` / `#000000` (presque noir).
- Secondaires pastel : `#1f453d` (vert forêt), `#a2b6df` (bleu doux), `#dad4ec` (lavande), `#d5d4d0` (gris chaud).
- Dégradé décoratif chaud : `#ffecd2 → #ffc8a9 → #ffb199 → #ff8c7f → #ff6900` (touches solaires).
→ Ambiance : claire, aérée, crème + magenta signature, pastels féminins. Très "magazine déco".

## Patterns UI/UX (home & navigation)
- **Menu à facettes** : Par pièce / Par style / Par couleur (3 axes de navigation = forces du cocon, exposées dans le menu).
- **Grille visuelle "Quel meuble ou idée déco recherchez-vous ?"** — 25 catégories en vignettes images (navigation visuelle/shopping vers les silos).
- Articles en **cartes** (image + titre + date), pagination.
- **Fil d'Ariane** sur les catégories.
- **Footer 4 colonnes** (Pièces / Inspirations & styles / Conseils & DIY / Infos).
- CTA service ("Coaching déco") intégré dans le flux home.
- Newsletter en bas de home.
- Pas de pub display (UX épurée).
