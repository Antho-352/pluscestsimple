# hello-hello.fr — Articles, copywriting & monétisation (données collectées)

## Page HUB /decorer/ (« Décorer avec style et conscience »)
- **Landing éditoriale hybride** (pas une simple cat) : H1 "Décorer avec style et conscience", intro philosophique ("la déco, expression de notre identité").
- Distribue vers 5 piliers éditoriaux : Shopping · Tendances · DIY · Marques et créateurs · (D)écolo (éco-responsable).
- Rôle = **point de distribution sémantique** : narratif + routage vers les taxonomies (pièce/style/couleur) + contenus inspiration.
- Pagination (78 pages). Mega-menus.

## Type d'article A — "Où trouver / Les plus beaux X" (shopping/affiliation)
Ex : "Les plus beaux salons de jardin en bois en 2026"
- **2500-3000 mots**, dense.
- Structure : H2 "Pourquoi on aime…" (+ H3 comparatif matières) → H2 "Notre sélection" (H3 par sous-segment : lounge / tables / petits espaces) → H2 "Comment entretenir…".
- ~20 produits, marques variées (Kave Home, Maisons du Monde, Leroy Merlin, Ikea, Westwing).
- Présentation produit : image → description courte → CTA "Acheter" + marque + **parfois prix** (ex "Bari, 1199€").
- **Affiliation masquée** : track.effiliation.com, lb.affilae.com, click.linksynergy.com, shortlinks fnty.co / c3po.link.
- ❌ Aucune mention de transparence affiliation (corps ni footer).
- Ton (verbatim) : "on ne se brûle point les fesses en s'asseyant comme sur du métal" · "On salue les imputrescibles acacia et teck" · familier, humour doux, pédagogique.
- 5-6 liens internes (catégories + articles connexes).

## Type d'article B — Listicle/comparatif "Les 20 meilleurs X"
Ex : "Canapé convertible : les 20 meilleurs modèles – 2026"
- **2500-3000 mots**. 20 modèles en **sections H2 thématiques** ("le plus compact", "le moins cher") — PAS un H2 par produit.
- Chaque produit : image + nom + marque + paragraphe technique + encadré **"Notre avis"** + lien affilié.
- Liens affiliés (Maisons du Monde, But, Ikea, Homifab) via linksynergy / fnty.co / c3po.link. Prix souvent absents.
- Ton recommandatif : "C'est clairement le couteau suisse du canapé-lit !" · "Probablement l'un des meilleurs pour dormir tous les jours."
- Maillage modéré + bloc "Publications similaires" (3).

## Type d'article C — Conseil court "Comment aménager X"
Ex : "Comment aménager son entrée ?"
- **~350 mots**, court, scannable, 11 photos.
- Structure par configuration (grande entrée / couloir étroit) en paragraphes (peu de H2).
- Ton "on" inclusif, injonctif positif : "On accroche des patères…", "On n'hésite pas à ajouter un joli miroir…", "Last but not least, on choisit une jolie porte."
- **Mixte** : conseil + liens produits (Bel'M portes, Brita Sweden) via Effiliation.
- **13 liens internes** (articles connexes + catégories pièce/style/couleur) = clustering thématique fort.

## Synthèse monétisation
1. **Affiliation** (cœur) : réseaux Effiliation, Affilae, LinkSynergy ; liens masqués/redirecteurs ; encadrés "Notre avis".
2. **Partenariats marques** (collections capsules, articles sponsorisés marques).
3. **Services** : coaching déco 1h30 visio, home staging.
4. **Livres** (3 ouvrages).
5. Pas de pub display (≠ notre modèle actuel display).

## Points faibles repérés (à FAIRE MIEUX)
- Pas de transparence affiliation (risque légal FR / DGCCRF).
- Bloque les bots IA (perd la visibilité GEO/IA).
- Catégories doublonnées (chambre-2, cuisine-2, cuisine-3, vintage + styles/decoration-vintage) → dette de taxonomie.
